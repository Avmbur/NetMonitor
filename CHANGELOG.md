# Журнал изменений NetMonitor

Пользовательские изменения по выпускам.

## 1.0 — 2026-09-27

- Первый публичный выпуск.
- Монитор `nmserver` и агент `nmagent` для серверов Ubuntu, amd64 и arm64.
- Сетевая активность парка в одном окне: процессы, адреса, порты, DNS-имена, правила, состояние соединений и трафик.
- Обучение на неизвестных контактах, правила, группы адресов, ручные блокировки и автобаны за сканирование портов и перебор SSH.
- Тревоги, история, аудит действий администратора и 19 отчётов с выгрузкой в CSV.
- Связь агента с монитором по HTTPS с взаимной проверкой сертификатов; при обрыве агент копит события в локальной очереди.
- Одна база SQLite с пределом размера: новые данные вытесняют самую старую историю. Один сменяемый снимок базы.
- Окно «by AVMBUR» с версией и датой выпуска.
